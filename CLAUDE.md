# Lab CPET tool — notes for Claude

Read this first in every session. It keeps decisions that are easy to lose when a long conversation is summarised.

## What it is
A single-file, browser-only HTML tool for exercise physiology labs (kept general, no institution named): COSMED gas data (+ Lode power, + blood lactate) →
protocol view, VT1/VT2 and VO₂peak (incremental), VT1 per 5-step test, prolonged-trial analysis, LT1/LT2, Word reports.
Created by SangHoon (Andrew) Yoon. Goals, scope and version history: Claude Doc "Lab CPET Tool: Changes and Goals"
(https://claude.ai/artifact/QNgUJBLxd9fZ8z6k4HpbQr). User guide: Claude Doc "Lab CPET Tool: User Guide"
(doc 6deecae8-ae85-48da-97b6-1a9475e93582). Update both with each release.

## Scope decisions (from Andrew)
- Gas alone or gas + lactate. Lactate-only tests stay with Exphyslab. No VO₂ lag correction, no prescription calculator.
- Researchers place thresholds; suggestions (classical, Oxynet) only assist. Participant names stay visible (no de-identification).
- Data never leave the browser. Results must be validated against the lab's usual method (Exphyslab, Excel).
- Credit "created by SangHoon Yoon"; cite Oxynet papers and lactater.

## Layout
- `src/parse.js` COSMED/Lode readers · `src/gdcore.js` shared maths · `src/protocol.js` stage detection, joins, suggestions, checks
- `src/oxynet.js` + `src/oxynet_models.js` pyoxynet 1.0.2 CNN/LSTM in plain JS (matches pyoxynet to 3e-7)
- `src/lactate.js` port of lactater 0.3.0 (MIT). Matches Exphyslab on lactater demo data to 0.0 W except Log-log (+0.1 W)
- `src/example.js` simulated incremental cycling test (COSMED layout, power in the file, lactate per stage) for "Try an example test" and the "What to look for" charts (src/app/14b); no real person
- `src/docx.js` Word writer (stored zip); `report/*.xml` styles from the clinic template → `src/docx_parts.js` (generated by build.py)
- `src/app/NN-name.js` UI in ordered parts sharing one scope (see src/app/README.md); build.py joins them into `src/app.js` (generated, git-ignored, never edit). Tabs: protocol / incremental ("Thresholds and VO₂peak") / steps / prolonged / lactate / summary
- `python3 build.py` → `dist/lab-cpet-tool.html` (Plotly 2.35.2 and SheetJS 0.18.5 inlined)

## Conventions
- `VERSION` in app.js: minor for features, patch for fixes. Bump with each release.
- Instructions/notes on tabs go in (i) pop-ups: mark an element `data-info="<target id>"`.
- Undo: state = `S.set` + `S.picks`, checkpointed after each click/change/keyup (keep new state in those two objects).
- Left-out periods (`S.set.leaveOut`, seconds) drop breaths in computeD, so every tab and protocol respects them.
- Oxynet input always excludes flagged outlier breaths (min-max scaling is fragile to single extreme breaths).
- Threshold status: a line is "checked" only when an explicit pick exists (moved, typed, method chosen, or Confirm). `statusOf(source)` gives the export status.
- Licence MIT (© 2026 SangHoon Yoon); third-party notices in THIRD_PARTY_NOTICES.md. `.github/workflows/pages.yml` publishes dist to GitHub Pages on push to main once the repo is public.
- Caveat ("a tool to help, not to rely on"): `CAVEAT` in 00-core; shown on the start page, Summary, footer, research report and README.
- Plain, short user-facing text; no abbreviations unexplained.
