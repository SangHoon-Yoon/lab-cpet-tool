## What it is
A single-file, browser-only HTML tool for exercise physiology labs (kept general, no institution named): COSMED gas
data (+ Lode power, + blood lactate) → protocol view, VT1/VT2 and VO₂peak (incremental), VT1 per 5-step test,
prolonged-trial analysis, LT1/LT2, Word reports. Created by SangHoon Yoon. Data never leave the browser;
threshold suggestions only assist; credit "created by SangHoon Yoon" and cite the Oxynet papers and lactater.

## Layout
- `src/parse.js` COSMED/Lode readers · `src/gdcore.js` shared maths · `src/protocol.js` stage detection, joins, suggestions, checks
- `src/oxynet.js` + `src/oxynet_models.js` pyoxynet 1.0.2 CNN/LSTM in plain JS (matches pyoxynet to 3e-7)
- `src/lactate.js` port of lactater 0.3.0 (MIT). Matches Exphyslab on lactater demo data to 0.0 W except Log-log (+0.1 W)
- `src/example.js` simulated incremental cycling test (COSMED layout, power in the file, lactate per stage) for "Try an example test" and the "What to look for" charts (src/app/14b); no real person
- `src/docx.js` Word writer (stored zip); `report/*.xml` styles from the clinic template → `src/docx_parts.js` (generated by build.py)
- `src/app/NN-name.js` UI in ordered parts sharing one scope (see src/app/README.md); build.py joins them into `src/app.js` (generated, git-ignored, never edit). Tabs: protocol / incremental ("Thresholds and VO₂peak") / steps / prolonged / lactate / summary
- `python3 build.py` → `dist/lab-cpet-tool.html` (Plotly 2.35.2 and SheetJS 0.18.5 inlined)

## Conventions
- `VERSION` in app.js: minor for features, patch for fixes. Bump with each release.
- Instructions/notes on tabs go in (i) pop-ups: mark an element `data-info="<target id>"`.
- Undo: state = `S.set` + `S.picks`, checkpointed after each click/change/keyup (keep new state in those two objects).
- Start-page choices: `S.set.type`, `S.set.sport` ('run' | 'cycle') and `S.set.data` ('gas' | 'lac' | 'both'; `dataMode()` decides the tabs). All optional: with none, the test is worked out from the file. Lactate only with no gas file uses an empty recording (`S.gas.blank`, made by `blankGas()` in 01-files) so the usual pipeline still runs.
- Stages: `S.set.stages` ({unit, list: [{t0, dur, p}]}, seconds) replaces the intensity everywhere when set (Stages block `#sBox`: `buildStages`, `drawStageChart` with an editing layer `#sto`, in 03; `fromStages` in protocol.js). Applying entered steps or blocks, or changing the source, clears it. Rests between stages (≤ `REST_MAX` s, slower or stopped) stay in one incremental run; `pr.inc.rests` are dropped in computeD unless `set.inc.dropRests === false`.
- Settings objects are filled in place (`lacSet()`, `repInfo()`): never replace them with a copy, or forms holding the old object stop working.
- Left-out periods (`S.set.leaveOut`, seconds) drop breaths in computeD, so every tab and protocol respects them.
- Oxynet input always excludes flagged outlier breaths (min-max scaling is fragile to single extreme breaths).
- Threshold status: a line is "checked" only when an explicit pick exists (moved, typed, method chosen, or Confirm). `statusOf(source)` gives the export status.
- Licence MIT (© 2026 SangHoon Yoon); third-party notices in THIRD_PARTY_NOTICES.md. `.github/workflows/pages.yml` publishes dist to GitHub Pages on push to main once the repo is public.
- Caveat ("a tool to help, not to rely on"): `CAVEAT` in 00-core; shown on the start page, Summary, footer, research report and README.
- Plain, short user-facing text; no abbreviations unexplained.
- "What's new" on the start page: `WHATS_NEW` in 00-core. Update its version and points (in Andrew's style: short, plain, direct) when a release changes results or how people work; the note reappears for everyone.

## Tests
- Setup once: `npm install` then `npx playwright install chromium`. Python 3 is needed for `build.py`.
- Everything: `npm test` (build, simulated files, unit tests, browser tests e2e … e2e29). Unit only: `npm run test:unit`.
- Paths come from `test/paths.js` (samples: `LABCPET_SAMPLES`, else `../lab-cpet-private/samples`, else `../samples`; downloads: `DL` or a temp folder).
- Run the full set before sending a build; tests that read hidden boxes must be updated when the UI changes on purpose.
- `test/oxy_ref.py` + `test/oxy_compare.js` compare with pyoxynet itself (needs Python with pyoxynet; optional).
